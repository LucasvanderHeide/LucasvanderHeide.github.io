7 Future research

7.0.1 So, what next?

A useful next step would be to investigate the dose-response relationship for each chemical. The R package drc can be used to fit and plot dose-response curves (Ritz et al., 2015).

For each chemical, the following steps can be followed using the normalized data:

  1. Fit a dose-response model. Use the drm() function in combination with the four-parameter log-logistic model LL.4(). The concentration is used as the independent variable and the normalized response as the dependent variable.

  2. Inspect the model. Use summary() to view the estimated model parameters and plot() to display the observed data together with the fitted dose-response curve. Check whether the curve describes the general pattern in the data.

  3. Estimate the IC50. Use the ED() function to estimate the concentration at which the response is reduced by 50% relative to the fitted response range. This value is also referred to as the ED50 in the drc package.

  4. Evaluate the results. Record the estimated IC50/ED50 and its confidence interval. Check how well the model fits the observed data and whether the estimate is reliable. For example, a poor fit or a wide confidence interval would make the estimate less reliable.

In short, this analysis helps describe the relationship between the concentration of a chemical and its biological effect. It also makes it possible to compare the chemicals based on their estimated IC50 values.
